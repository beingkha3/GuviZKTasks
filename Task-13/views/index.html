Task-13 — Secure Password Reset Flow

A complete password reset workflow built with Node.js, Express, MongoDB, React, and Bootstrap.

API Endpoints

MethodEndpointDescription
POST /api/auth/forgot-password Generate a secure reset token and email a reset link to the user. Returns a generic success regardless of whether the email exists.
GET /api/auth/reset-password/:token Verify that a reset token exists in the database and has not expired. Returns 400 for invalid tokens, 410 for expired ones.
POST /api/auth/reset-password/:token Accept a new password, re-validate the token, hash the password, clear the token fields, and save the updated user.

Frontend Routes (React + Bootstrap)

RoutePage
/forgot-passwordEmail submission form
/reset-password/:tokenToken verification + new password form
/loginSuccess handoff screen

Security

  • Raw token is emailed; only a SHA-256 hash is stored in MongoDB.
  • Token expires after 15 minutes (configurable via RESET_TOKEN_EXPIRY_MINUTES).
  • Token is one-use: cleared immediately after a successful reset.
  • Passwords are hashed with bcryptjs (cost factor 12).
  • Forgot-password returns a generic message to prevent account enumeration.
