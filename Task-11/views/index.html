Recipes API

A RESTful API for managing recipes. Built with Node.js, Express, and Mongoose.

Endpoints

MethodEndpointDescription
POST/api/recipesCreate a new recipe
GET/api/recipesGet all recipes
GET/api/recipes/:idGet a recipe by ID
PUT/api/recipes/:idUpdate a recipe by ID
DELETE/api/recipes/:idDelete a recipe by ID

Recipe Schema

{
  "name": "String (required)",
  "ingredients": ["String (required)"],
  "instructions": "String (required)",
  "cuisine": "String",
  "prepTime": "Number (minutes)",
  "cookTime": "Number (minutes)",
  "servings": "Number"
}
