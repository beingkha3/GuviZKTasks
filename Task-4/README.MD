# Memory Game

A simple Memory (Concentration) Game built using HTML, CSS, and JavaScript.

## How to Run
1. Create a folder (e.g. Task-4)
2. Add the following files:
   - index.html
   - style.css
   - script.js
   - README.md
3. Open index.html in a browser.

## How to Play
- Click a card to reveal it.
- Click another card to find a matching pair.
- Matching cards stay open.
- Non-matching cards flip back.
- Match all pairs to win.

## Features
- Shuffle on restart
- Move counter
- Timer
- Responsive design
